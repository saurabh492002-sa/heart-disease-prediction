# Heart Disease Prediction Using Random Forest

## Project Overview
This project uses Machine Learning to predict the presence of heart disease based on patient health data.
A Random Forest Classifier is trained and evaluated using Python and Scikit-learn.

## Objectives
- Analyze heart disease data.
- Clean and preprocess the dataset.
- Explore data using visualizations.
- Train a Random Forest classification model.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the dataset.
2. Handle missing values.
3. Detect and handle outliers.
4. Encode categorical features.
5. Split data into training and testing sets.
6. Train the Random Forest Classifier.
7. Evaluate predictions using accuracy, classification report, confusion matrix, and ROC-AUC.
8. Visualize feature importance.

## Model Performance
- **Testing Accuracy:** Approximately 83%

## Project File
## Project Files

- `Heart_Disease_Prediction.ipynb` — Jupyter Notebook containing data analysis, visualization, model training, and evaluation.
- `Heart.csv` — Dataset used for the project.
- `requirements.txt` — Required Python libraries.

## How to Run the Project

1. Clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Open `Heart_Disease_Prediction.ipynb` in Jupyter Notebook.
4. Update the dataset path in the notebook to:

   `Heart.csv`

5. Run the notebook cells in order.
